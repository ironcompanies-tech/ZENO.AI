Get Started

CLICK ANY OF THE BUTTONS TO START A SPECIFIC TASK — EACH BUTTON IS A GATEWAY INTO A DIFFERENT WAY OF WORKING WITH AI.

Think — Rapid exploration tools for brainstorming and system design. Use Think when you want to map possibilities, define problems, or rapidly iterate on high-level ideas.

Create — Visual and audio studios for turning concepts into shareable artifacts. Create provides templates, generative styles, and live previews.

Code — A lightweight sandbox for prototyping, testing, and refining logic. Code connects to real-time logs and versioned snippets.

Imagine — Open-ended experimental tools that remix data, style, and intent to surface surprising results.

Each mode includes contextual tips, example prompts, and clear controls so you always know how to steer outputs.
